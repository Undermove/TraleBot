# Каталог глаголов: откуда что взято

Грузинские формы в каталоге никто не генерирует моделью: они из открытых источников ниже. Руками
написаны русские переводы (`ru.json`), списки исключений и одно исключение из правила — `supplements.json`:
времена, которых нет в таблице Викисловаря, у глаголов, без которых каталогу нельзя («знать», «хотеть»).

### Дополнения по грамматике (`supplements.json`)

Таблицы Викисловаря у «знать» (იცის) и «хотеть» (უნდა) — только настоящее и имперфект, хотя будущее и
прошедшее у них в речи на каждом шагу. Ряды вписаны руками по схеме глаголов-перевёртышей (как «любить»,
у которого таблица полная) и сверены с корпусами. Сборка их проверяет:

- клетки, которые в таблице Викисловаря есть, дополнение не трогает;
- ряд берётся, только если не меньше половины его форм встречаются в корпусах (`attested.bloom` —
  Leipzig + Tatoeba, см. `build-attested.mjs`); редкие времена, которых в текстах нет, не вписываются;
- у каждой записи — `evidence` (на чём держится) и ссылки `sources`.

**Глагол целиком (`verb`).** У იცნობს «знать кого-то» статья в Викисловаре есть, а таблицы нет вовсе
(помета `rfinfl`), поэтому в `verbs.raw.json` его нет. Без него не сказать «я знаю тебя»: у იცის формы
«кого» нет (გიცი в корпусах не встречается). Запись с полем `verb` (масдар, толкование, ссылка на статью)
добавляет глагол в сборку (`hand-written.mjs`); его формы — только настоящее, имперфект и «чтобы знал»
(18 форм, все в корпусах), по схеме ითხოვს из таблицы Викисловаря. Прошедшее и будущее с приставкой გა-
значат уже «познакомиться» (статья გაიცნობს) — они в `noTense`. Частотность и предложения Tatoeba для него
посчитаны тем же `collect-evidence.mjs` (на тех же выгрузках он переписал `sentences.raw.json` и числа
корпусов остальных глаголов байт в байт).

**Две таблицы в одну (`verb.tables`).** «Садиться» в Викисловаре — два глагола: у ჯდება заполнены только
я/ты/он, у სხდება — только мы/вы/они (остальные клетки n/a, выгрузка такие таблицы отбрасывает). Примечание
в обеих статьях: ჯდება — когда садится один, სხდება — несколько или группа. Запись складывает их в одну
карточку клетка в клетку; формы — источник, не грамматика, поэтому `supplemented` у карточки нет.

**Что ещё такое бывает и почему не в каталоге (27.10.2026).** «Один / много» и «живое / неживое» — частая
путаница: ზის / სხედან «сидит / сидят», დგას «стоит», წევს / დევს «лежит (человек / вещь)», აგდებს / ყრის
«бросает одно / много», კლავს / ხოცავს «убивает одного / многих», მიაქვს / მიჰყავს «несёт / ведёт», а также
მოსწონს «нравится», ახსოვს «помнит». Таблиц спряжения у них нет ни в Викисловаре (живые статьи сверены
27.10.2026), ни в UniMorph (кроме კლავს, მოსწონს, ახსოვს); пометок о числе, кроме ჯდება / სხდება, нет.
Значит, нужен ещё один источник форм — пока не добавлены.

`noTense` — времени у глагола нет вовсе (у «знать» нет «узнал»): карточка показывает на его месте, что
говорят вместо. В `verbs.json` у такого глагола есть `supplemented` (какие времена вписаны) и `noTense`;
карточка подписывает дополненные времена «по грамматике, сверено с корпусами текстов».

### Оговорки

- **Субтитры `ka_50k.txt` засорены.** Верх списка — не грузинские слова, а кириллические субтитры,
  прочитанные в грузинской кодировке (бессмысленные сочетания букв). Настоящие грузинские формы в списке есть,
  но их мало: ненулевая частота набирается только у 91 глагола из 226. Поэтому вес источника вдвое ниже,
  а основой служат корпуса Leipzig.
- **Леммной частотности грузинского в открытом доступе не нашлось.** Грузинский национальный корпус (GNC)
  размечен по леммам, но выгрузку не раздаёт; `wordfreq` грузинского не содержит. Поэтому частота глагола —
  сумма частот его словоформ по спискам словоформ.
- Выгрузка kaikki не содержит номера ревизии статьи; воспроизводимость держится на sha256 файла выгрузки.

## Как пересобрать

```sh
# 1. парадигмы из выгрузки (нужна только здесь)
node scripts/verbs/extract-kaikki.mjs ~/Downloads/kaikki.org-dictionary-Georgian.jsonl
node scripts/verbs/compare-live.mjs        # сверка с 23 глаголами, снятыми с живых страниц

# 2. частотность и предложения (внешние файлы нужны только здесь)
node scripts/verbs/collect-evidence.mjs --tatoeba kat_pairs.json \
     --web kat-ge_web_2019_300K-words.txt --news kat_newscrawl_2016_300K-words.txt \
     --wiki kat_wikipedia_2021_300K-words.txt --subs ka_50k.txt

# 3. каталог и таблица для вычитки (ничего внешнего не нужно)
node scripts/verbs/build-catalog.mjs       # --check — только проверки, --force — разрешить уменьшение
```

`kat_pairs.json` — грузинские предложения Tatoeba с переводами: массив `{ id, ka, ru: [..], en: [..] }`,
собирается из еженедельных выгрузок Tatoeba (`sentences`, `links`).

Шаги 1 и 2 запускаются редко (обновилась выгрузка); шаг 3 — после любой правки `ru.json`,
`verbs.skip.json`, `sentences.skip.json`. Все три шага детерминированы: одинаковый вход — одинаковый
выход, байт в байт.

## Названия действия, вписанные по словарям (сверка 12.10.2026)

Заголовок карточки — название действия. У девяти глаголов выгрузка Викисловаря его не давала (заголовком
становилась сама лемма — «он есть» вместо «быть») либо давала слово другого глагола (у «ходить» — სვლა,
то же, что у «идти»). Они вписаны в `titles.json`; формы спряжения при этом не менялись. Каждое слово
сверено по открытым словарям, страницы сняты 12.10.2026:

- [ganmarteba.ge](https://www.ganmarteba.ge/about) — электронный словарь современного грузинского
  (ლინგვისტური ტექნოლოგიების ჯგუფი, 41 468 статей): у слова помета «საწყისი» (название действия) и
  список глаголов, к которым оно относится («ზმნები»);
- толковый словарь грузинского языка (ქეგლ) на [ena.ge](http://ena.ge/explanatory-online): формула
  «სახელი … ზმნის მოქმედებისა» — «название действия глагола …»;
- английский, русский и грузинский Викисловари (в ссылках — номер ревизии).

## Данные для самопроверки агента перевода

Когда слова нет в каталоге, сервер может спросить модель (см. `GeorgianTranslationPipeline`). Ответ модели
не принимается на веру: его сверяет код по двум файлам, собранным из открытых источников.

| Файл | Что в нём | Из чего собран | Лицензия источника | Размер |
|---|---|---|---|---|
| `src/Trale/Verbs/lexicon.json` | 1047 грузинских глаголов: лемма, масдар, есть ли таблица спряжения, английские толкования, русские переводы (у 97; неверно привязанные вычеркнуты в `lexicon-ru.skip.json`) | English Wiktionary — та же выгрузка kaikki, что для каталога; русский Викисловарь — выгрузки Wiktextract с kaikki.org: грузинские статьи (`ruwiktionary/Грузинский`, 7,6 МБ) и блоки переводов «Грузинский» из русских статей (`ruwiktionary/Русский`, 1,8 ГБ — читается потоком, на диск не сохраняется) | CC BY-SA 4.0 (и GFDL) | 104 КБ |
| `src/Trale/Verbs/attested.bloom` | фильтр Блума: 253 802 грузинские словоформы, встретившиеся в текстах (≈1 % ложных «встречалась»); сами слова из него не восстановить | три корпуса Leipzig (те же, что для частотности, файлы `*-words.txt`, слова с суммарной частотой ≥ 2) и предложения Tatoeba | CC BY 4.0; CC BY 2.0 FR | 317 КБ |

sha256 входных файлов записаны в `lexicon.json` → `sources`. Сборка (внешние файлы нужны только здесь, в git не кладутся):

```sh
# переводы на грузинский из русских статей русского Викисловаря — поток, фильтр оставляет ~11 тыс. строк
curl -s https://kaikki.org/ruwiktionary/Русский/kaikki.org-dictionary-Русский.jsonl \
  | python3 -c "import sys,json
for l in sys.stdin:
    if '\"ka\"' not in l: continue
    e=json.loads(l); t=[x for x in e.get('translations',[]) if x.get('lang_code')=='ka' and x.get('word')]
    if t: print(json.dumps({'word':e.get('word'),'pos':e.get('pos'),'ka':[{'word':x['word']} for x in t]},ensure_ascii=False))" > ru-ka.jsonl

node scripts/verbs/build-lexicon.mjs kaikki.org-dictionary-Georgian.jsonl \
     --ru-ka kaikki.org-dictionary-Грузинский.jsonl --ru ru-ka.jsonl
node scripts/verbs/build-attested.mjs --tatoeba kat_pairs.json \
     kat-ge_web_2019_300K-words.txt kat_newscrawl_2016_300K-words.txt kat_wikipedia_2021_300K-words.txt
```

Что по ним проверяется (код — `VerbProposalResolver`): лемма, предложенная моделью, — настоящий глагол
Викисловаря либо глагол, чьи формы встречаются в текстах; если русский Викисловарь переводит запрошенное
слово другими глаголами, предложение модели вне этого списка отклоняется; перевод и масдар берутся из
источника, когда они там есть; формы, которые модель составила сама (таблицы нет нигде), пересчитываются
по корпусу, и глагол без единой встретившейся формы не сохраняется. Для сверки: у глаголов каталога в
корпусах встречается в среднем три четверти форм карточки (медиана 77 %, у каждого десятого — меньше 47 %).
