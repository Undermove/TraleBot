# Комиксы «кадр под замком»

История — это файл `<id>.json` в этой папке плюс кадры в `src/Trale/miniapp-src/public/stories/<id>/<хеш>/`.
Истории принадлежат глаголу и открываются с его карточки. Сервер читает их при старте (`LoadVerbStories`)
и отдаёт через `GET /api/miniapp/verbs/{id}/stories`.

Главное правило: **грузинский текст реплики в файл истории не пишется**. Кадр называет предложение из
каталога по его id в Tatoeba, а сервер подставляет текст сам. Грузинскими буквами в файле записаны только
формы глагола (`verb`, `form`, `options`) — их копируют из каталога, и тест сверяет каждую с таблицей.

## Как добавить историю

### 1. Выбрать предложения

Предложения берутся из `scripts/verbs/sentences.raw.json` (выборка Tatoeba: id, `ka`, `ru`). Подойдут те,
в которых есть форма нужного глагола из `src/Trale/Verbs/verbs.json`. Найти кандидатов:

```bash
node -e '
const v = require("./src/Trale/Verbs/verbs.json").verbs.find(v => v.lemma === process.argv[1])
const forms = new Set(Object.values(v.tenses).flat(2))
for (const s of require("./scripts/verbs/sentences.raw.json")) {
  const form = (s.ka.match(/[ა-ჰ]+/g) ?? []).find(w => forms.has(w))
  if (form) console.log(s.id, form, s.ka, "—", s.ru)
}' <лемма глагола>
```

Из них складывается сюжет на 5–7 кадров. Форма должна стоять в предложении ровно один раз.

### 2. Написать сценарий — `<id>.json`

```json
{
 "id": "go-fishing",
 "verb": "<лемма из каталога>",
 "title": "Бомбора идёт на рыбалку",
 "images": "go-fishing/<хеш — его напечатает шаг 4>",
 "frames": [
  {
   "image": "f1",
   "who": "Кот",
   "scene": "Кот видит Бомбору с удочкой.",
   "sentence": 8475459,
   "form": "<форма глагола из этого предложения>",
   "mode": "choose",
   "options": ["<та же форма>", "<другие формы этого глагола>"]
  }
 ]
}
```

- `id` совпадает с именем файла: латиница, цифры, дефис.
- `mode`: `choose` — выбрать форму из `options`; `type` — набрать её на грузинской клавиатуре;
  `build` — собрать всю фразу из слов. Начинать лучше с `choose`, `type` ставить на форму, которая уже встречалась.
- `options` — только настоящие формы этого же глагола. Объяснение «что значит неверная форма» приложение
  строит само из времени и лица, по-русски его писать не нужно.
- `scene` — что происходит на картинке, по-русски, одной фразой. `who` — кто говорит.
- `adaptedRu` — только если перевод Tatoeba не ложится в сюжет (в грузинском нет рода: «Она пошла домой» →
  «Он ушёл домой»). Поле само и есть отметка «перевод подогнан»: оригинал остаётся в каталоге и уходит в
  мини-апп как `sourceRu`. Менять смысл нельзя, только род, лицо говорящего и порядок слов.
- Про `build`: порядок слов в грузинском гибкий, а проверить чужой порядок нам нечем. Читалка не называет
  другой порядок ошибкой: сначала подсказывает первое слово источника, со второго раза показывает фразу
  источника и пускает дальше. Берите для `build` короткие предложения в 3–4 слова.

### 3. Пересобрать каталог

```bash
node scripts/verbs/build-catalog.mjs
```

В карточку глагола попадает не больше четырёх предложений на форму. Предложения, на которые ссылается
история, сборка добавляет в карточку всегда, сверх этого лимита, — поэтому после правки сценария каталог
надо пересобрать и закоммитить `verbs.json`. Если id нет в выборке или он в `sentences.skip.json`, сборка
упадёт с понятной ошибкой.

### 4. Нарисовать кадры

Промпты лежат в `scripts/verbs/story-art/<id>.prompts.json`: общий `style` и по сцене на кадр. Правила:

- Стиль общий для всех историй — скопируйте `style` из `scripts/verbs/story-art/go-fishing.prompts.json` и поменяйте только
  описание второго героя.
- Бомбора рисуется по образцу `scripts/verbs/story-art/mascot-reference.png` (он уходит в модель первым изображением), первый
  готовый кадр — вторым образцом во все следующие, чтобы герои не менялись от кадра к кадру.
- Квадрат 1024×1024, один кадр без рамки. **Никакого текста на картинке**: ни букв, ни облачков — реплика
  живёт под кадром.
- Сцена описывается по-английски, одно действие на кадр, и должна совпадать с `scene` в сценарии.

```bash
python3 scripts/verbs/story-art/gen_frames.py <id> /tmp/<id>-png   # нужен ключ в ~/.config/openai/key
```

PNG в репозиторий не кладём. Неудачный кадр — удалить PNG и запустить ещё раз.

### 5. Сжать и выложить

```bash
node scripts/verbs/story-frames.mjs <id> /tmp/<id>-png
```

Скрипт делает из каждого `fN.png` три файла теми же командами, что ниже, считает хеш набора, кладёт файлы
в `src/Trale/miniapp-src/public/stories/<id>/<хеш>/` (старую версию удаляет) и печатает строку
`"images": "<id>/<хеш>"` — её надо вставить в сценарий.

```bash
cwebp -quiet -q 82 -resize 800 0 f1.png -o f1-800.webp   # кадр для телефонов с плотным экраном
cwebp -quiet -q 80 -resize 480 0 f1.png -o f1-480.webp   # кадр для экранов попроще
cwebp -quiet -q 30 -resize 32 0  f1.png -o f1-ph.webp    # заглушка: видна под замком и пока кадр грузится
```

Хеш в пути — это версия: адрес кадра никогда не отдаёт другие байты, сервер ставит на `/stories/`
`Cache-Control: immutable`. Поэтому файлы в папке руками не меняют — только через скрипт.

Ориентир по весу: кадр 800 px — 50–65 КБ, 480 px — 26–33 КБ, заглушка — около 300 байт. История из шести
кадров на телефоне — около 350 КБ, и грузится она по кадру: под замком скачивается только заглушка.

### 6. Проверить

```bash
dotnet test tests/IntegrationTests/IntegrationTests.csproj --filter "FullyQualifiedName~VerbStoryTests" -nologo -v q
```

Тест проверяет каждую историю из этой папки: предложение есть в карточке глагола; форма стоит в нём ровно
один раз и есть в таблице глагола; все варианты `choose` — формы этого глагола; у каждого кадра есть три
файла; имя папки с кадрами равно хешу её содержимого; грузинского текста вне `form` и `options` в файле нет.

Те же проверки (кроме файлов кадров) сервер делает при старте: история с ошибкой не роняет приложение, а
пропускается с записью `Verb story skipped — …` в логе.
