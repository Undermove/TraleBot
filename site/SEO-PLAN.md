## Конкуренты в выдаче (русскоязычные запросы)

- **geolang.ru** — главный. Уроки по 2500–3000 слов с таблицами склонения, упражнениями, аудио; есть справочник спряжения глаголов (`/verbs`), частотный словарь, транслитератор. Держит топ по «дательный падеж в грузинском», «спряжение грузинских глаголов», «грузинский алфавит с произношением».
- **za7gorami.ru** — личный блог, страница про алфавит на 2500+ слов с транскрипцией, фото вывесок, живой тон. Топ по «грузинский алфавит для начинающих».
- **gruzinskij.ru, languages42.ru, georgia.iliko.ru, gruziyagid.ru** — учебники-справочники среднего качества.
- **Википедия, otvet.mail.ru, форум irakly.info, группы в ОК** — заполняют выдачу по «падежи в грузинском», «эргативный падеж»: слабая конкуренция, здесь окно.
- Приложения (50languages, LingWing, Ling, LinGo) забирают запросы «приложение учить грузинский» через сторы и большие бюджеты — не наша поляна.

Вывод: страница, чтобы попасть в топ-5, должна быть не короче geolang (2000+ слов), с таблицами, и отличаться личным опытом и объяснением «почему так», которого у справочников нет. Три текущие страницы по 400–700 слов — только каркас.

## План по приоритету

1. **Search Console + Яндекс.Вебмастер** (владелец). Токены в `site/site.config.json` → деплой → подтвердить → отправить `https://tralebot.com/sitemap.xml`. Через 2–3 недели там появятся реальные запросы и позиции.
2. **Снять `draft: true`** с трёх страниц после переписывания текста (владелец).
3. **Cloudflare** (владелец): Redirect Rule `www.tralebot.com/*` → `https://tralebot.com/$1`, 301.
4. **Cloudflare, AI-боты** (владелец): в Security → Bots выключить «Block AI bots» или хотя бы разрешить GPTBot/ClaudeBot/PerplexityBot. Ответы ChatGPT/Perplexity — второй источник трафика по грамматическим вопросам.
5. **Контент: 30 страниц под конкретные вопросы** (владелец пишет, агент верстает и линкует). Список тем ниже.
6. **Ссылки**: статья на Хабре/vc.ru «как я учил грузинский» со ссылками на 3–4 страницы; посты в каналах про Грузию и релокацию; ссылка из Telegram-описания бота на `/grammar/`.
7. **Глаголы**: датасет 30–50 частых глаголов, проверенный носителем, → генератор `/verbs/<глагол>` (агент). Это единственный путь к сотням страниц с длинным хвостом, как у geolang.

## Темы для страниц (по интенту запроса)

Формат каждой: вопрос в заголовке, ответ в первом абзаце, таблица, 5–10 примеров с переводом, 2–3 ссылки на соседние темы, кнопка в бота.

**Падежи и имена**
- Эргативный падеж: когда подлежащее получает -მა (сравнение настоящего и аориста)
- Дательный падеж как подлежащее: მიყვარს, მინდა, მაქვს — почему «мне любится»
- Родительный падеж и послелоги: -ის + შემდეგ / გამო / გარეშე
- Творительный vs обстоятельственный: -ით и -ად на одних словах
- Звательный падеж в живой речи: კაცო, ბიჭო, გოგო
- Множественное число: -ებ- перед падежным окончанием
- Склонение имён собственных: ნინო, გიორგი, დავითი
- Усечение основы: მეგობარი → მეგობრის (когда выпадает гласная)

**Глаголы**
- Четыре класса глаголов простыми словами (переходные, непереходные, чувства, положение)
- Аорист vs имперфект: «сделал» vs «делал»
- Приставки направления: მი-, მო-, წა-, შე-, გა-, ა-, ჩა-
- Версионные гласные: ვწერ / ვუწერ / ვიწერ
- Глаголы движения: მიდის, მოდის, დადის — таблица направлений
- Как сказать «у меня есть»: მაქვს vs მყავს
- Глагол «быть»: ვარ, ხარ, არის во всех лицах
- Будущее время и где берётся приставка
- Повелительное наклонение: მოდი, წადი, დაჯექი
- Условные предложения: თუ, რომ

**Местоимения, послелоги, числа**
- Личные местоимения и их склонение
- ეს / ეგ / ის — три указательных вместо двух
- Послелоги места -ში / -ზე / -თან с таблицей частых слов
- Послелоги направления -დან / -მდე / -კენ
- Двадцатеричный счёт: почему 50 — это «два по двадцать и десять»
- Порядковые числительные и дни недели
- Который час по-грузински

**Практические**
- Как читать вывески и меню: 20 слов, которые встречаются каждый день
- Как заказать в кафе: фразы с разбором грамматики
- Как назвать своё имя и откуда ты: ვარ + падежи
- Частые ошибки русскоязычных в грузинском

## Что нужно от владельца (по шагам)

1. Search Console: Добавить ресурс → «Префикс URL» `https://tralebot.com` → способ «Тег HTML» → прислать значение `content`.
2. Яндекс.Вебмастер: Добавить сайт → способ «Мета-тег» → прислать значение `content`.
3. Cloudflare: сделать Redirect Rule для `www` и решить по AI-ботам (или дать доступ агенту в панель).
4. Написать/переписать тексты трёх страниц и снять `draft`.
